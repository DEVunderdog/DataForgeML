# The Estimator Ladder steps down on Feasibility Terms

The MICE estimator was picked from one `NonlinearityTag` and one raw row count: `ComplexNonlinear` got a gradient booster at `n_rows >= gradient_boost_min_rows`, else a forest. The Feasibility Floor (ADR-0091) sets MICE's bounds for its cheapest estimator, `BayesianRidge`, so it is lenient for a block that lands on a hungrier one. We close that gap with the same two Feasibility Terms the floor already computed. The tag sets the most the block may get; a failed **Estimator Bound** steps it down one rung. Nothing in routing or the recipe reads a raw row count anymore, except the KNN Resource Ceiling, which reads memory.

## Status

accepted — resolves [Whether the two quantities govern the estimator pick and ADR-0062's hyperparameters](https://github.com/DEVunderdog/DataForgeML/issues/526) on map #528. Amends ADR-0011 (the tag is now a ceiling, not the pick), ADR-0091 (fills in the "hungrier estimator sits behind its own rule" hand-off), ADR-0092 (sets the Capability Ladder order; `Unpredictable` maps to an estimator), ADR-0062 and ADR-0089 (the `n_rows - 1` operand on `n_neighbors` is deleted, so the recipe reads no row count). Amended by ADR-0097: all four Estimator Bounds measured trivial or refuted and are deleted. The forest beats BayesianRidge most at the smallest sizes, and the booster loses to the forest on real frames up to 1,000 rows, so it leaves the ladder (`ComplexNonlinear` → forest; the booster only through `with_model_choice`). There is no downgrade and no thinnest-column reading. The donor guarantee attributed to `knn_min_usable_rows` is withdrawn: `KNNImputer` needs none. "`max_iter` and `tol` read no Feasibility Term" was checked and stands ([Measure the floor bounds and estimator bounds](https://github.com/DEVunderdog/DataForgeML/issues/543)).

## Decisions

- **Capability Ladder: KNN below MICE.** The middle Signal Tier takes KNN if it is feasible, else MICE; the top tier takes MICE if feasible, else KNN. One fixed order, so the tier alone decides. Given up: the entry path's old preference — a middle-tier Severe column that used to get MICE now gets KNN.
- **The Capability Ladder orders strategies only.** Tiers are per column; the estimator is per block, so two columns in different tiers share one estimator. Given up: no link between a column's signal strength and the model capacity it gets.
- **Estimator Ladder: `BayesianRidge` < `RandomForestRegressor` < `GradientBoostingRegressor`.** The block's winning tag sets its top rung: `Linear` → BayesianRidge, `MonotonicNonlinear` → forest, `ComplexNonlinear` → booster. `r2_gap` enters only through the tag; reading it again would put a second unmeasured threshold on the same number.
- **Two rungs carry Estimator Bounds, each a pair of Feasibility-Term bounds.** `random_forest_min_usable_rows`, `random_forest_min_rows_per_predictor`, `gradient_boost_min_usable_rows`, `gradient_boost_min_rows_per_predictor`. Both terms must pass, as in the floor. The forest is gated too, because from a floor set for BayesianRidge it is as hungry as the booster. `gradient_boost_min_rows` is deleted. BayesianRidge carries no bound: the floor is its bound. Given up: four new dials, a wider #519 sweep, and one or two may measure out trivial.
- **A failed bound downgrades; it never rejects.** Each column already passed the floor, so it is feasible. Rejecting on a block choice would let one thin column push a *different* column out of MICE, breaking ADR-0091's per-target rule. Given up: a thin column silently costs the whole block capacity — the signal below makes it not silent.
- **The block reads its thinnest column.** Each term is the minimum across MICE columns, using the exact values the floor computed (MICE's predictor count capped by `mice_max_nearest_features`). `IterativeImputer` trains one estimator clone per target on that target's observed rows, and an overfit equation feeds every later round. Forced columns (`per_column_strategy`) count: their equation trains on the block's estimator too. Given up: one thin column, forced or not, caps a rich block. The median was rejected — it would put a booster on the column most likely to overfit.
- **`Unpredictable` maps to BayesianRidge.** The `None` branch in the factory and the fitter's skipped block go. A column only reaches MICE with that tag when the Signal Score found a signal the probe missed, so the cheapest estimator is the honest match.
- **Reported on every MICE column, naming the bound.** A line such as `mice_estimator: ComplexNonlinear → RandomForestRegressor; downgraded from GradientBoostingRegressor: gradient_boost_min_rows_per_predictor failed on 'income' (12.0 < 20)` goes into each MICE column's signals, naming every failed term on every skipped rung. Naming the bound, not just the quantity, is what stops "passed the floor" and "failed the estimator" reading as a contradiction. Given up: a 30-column block repeats one line 30 times; routing gains no block-level signal slot.
- **Computed in `route` only.** `with_model_choice` and `author` check no bound: an explicit estimator is informed consent, as `author` computes no floor (ADR-0090, ADR-0091).
- **The `n_rows - 1` cap on `n_neighbors` is deleted.** `KNNImputer` already caps each column at its donor count (`min(n_neighbors, donors)`), and donors are exactly that column's Usable Rows, so the recipe's cap was a looser copy. `knn_min_neighbors`/`knn_max_neighbors` stay; `knn_min_usable_rows` guarantees donors. The recipe now reads no row count, so rigidity check (2) passes by construction. `k_capped` on `FitSignals` compares only against `knn_max_neighbors`. Given up: a thin column may run fewer donors than the recipe states.
- **`max_iter` and `tol` read no Feasibility Term.** Their operands — tag, block missingness, `r2_gap`, max pairwise `|r|`, complete-row fraction, IQR — describe coupling and missingness, not size. Reopened only if #519 shows convergence moving with Usable Rows.

## Considered Options

- **Gate only the booster.** Leaves the same gap one rung lower, on the forest.
- **Delete the booster branch.** It barely fires on the 7GB box (MICE OOMs at 5k rows), but that removes a real choice on the evidence of one machine.
- **Reject the strategy on a failed bound.** Makes a column's route depend on its siblings.
- **The entry path picks between MICE and KNN.** Turns the one escalation point back into five chains.
- **Cap `n_neighbors` at the block's minimum Usable Rows − 1.** Makes the recipe read block membership to copy what sklearn does per column.

## Consequences

- #519 measures the four Estimator Bounds alongside the floor and score dials, and checks that MICE convergence does not move with Usable Rows.
